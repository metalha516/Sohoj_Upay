# Synthetic Data & Exports

Deterministic synthetic data generation and export store for Bangladeshi MFS users.

## Synthetic Data Mandate
- Fictional, realistic data generated by seeded, deterministic code ($N \ge 600$ users, 12 months, $\ge 100\text{k}$ transactions).
- `is_synthetic = true` flagged across all records.
- Ground truth (`synthetic_ground_truth`) is quarantined separately from model training features.
- Exports are stored in `exports/` (git-ignored).
