# Frontend Service (Next.js)

Next.js (App Router) frontend providing the user dashboard and conversational coaching interface.

## Tech Stack
- Next.js (App Router), React, TypeScript
- Tailwind CSS, Recharts for financial visual analytics
- TanStack Query for client-side API state management

## Structure
- `app/`: Next.js App Router pages and layouts.
- `components/`: UI components (cards, charts, coach chat, transaction tables).
- `hooks/`: Custom React hooks for API state and queries.
- `services/`: API client service layer.
- `types/`: TypeScript type definitions matching backend Pydantic schemas.
- `lib/`: Helper utilities and formatters.
